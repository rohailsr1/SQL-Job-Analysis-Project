# Data Job Market Analysis: SQL Project 📊

## 📌 Introduction
In this project, I dive into the data job market to uncover the top-paying roles and the most in-demand skills for Data Analysts. Using a dataset of thousands of job postings, I've applied various SQL techniques to answer critical questions: 
* What are the top skills? 
* Where are the best opportunities? 
* How does salary vary across different roles?

---

## 📖 Background
As a self-directed learner transitioning into data analytics, I wanted to apply my SQL skills to a real-world problem. This project is modeled after the curriculum by **Luke Barousse**, using data that reflects actual job postings from 2023-2024. My goal was to move beyond basic queries and perform deep-dive analysis on the tools and trends currently shaping the industry.

## 🛠️ Tools I Used
To manage the data and extract insights, I leveraged the following:
- **SQL:** The backbone of my analysis, allowing me to query and manipulate large datasets.
- **PostgreSQL:** My chosen database management system for its robustness and industry standard.
- **pgAdmin 4:** My primary tool for database administration and writing SQL scripts.
- **VS Code:** For organizing my SQL files and maintaining my GitHub repository.

## 🔍 The Analysis
I structured my queries to answer five core questions:
1. **Top-Paying Data Analyst Jobs:** Identifying the highest-paying roles regardless of location.
2. **Skills for Top-Paying Jobs:** Pinpointing exactly which skills are required for those high-salary positions.
3. **Most In-Demand Skills:** Finding which skills are most frequently mentioned across all job postings.
4. **Top Skills based on Salary:** Analyzing which skills are associated with higher average pay.
5. **Most Optimal Skills to Learn:** Identifying the "sweet spot"—skills that are both in high demand and high paying.

Throughout this process, I utilized **CTEs (Common Table Expressions)**, **Subqueries**, and **Complex Joins** to connect job postings with company and skill tables.

## 💡 What I Learned
Completing this project significantly improved my technical workflow:
* **Advanced Querying:** I moved from simple `SELECT` statements to complex logic involving `GROUP BY` and multi-table joins.
* **PostgreSQL Mastery:** I gained hands-on experience setting up databases, importing CSV data using the `\copy` command, and managing schemas.
* **Logic over Syntax:** I realized that SQL logic is often more intuitive for data cleaning than Excel, especially when handling thousands of rows of data.
* **Data Storytelling:** I learned how to translate raw numbers into meaningful career advice.

## 🏁 Conclusions

- **The "Table Stakes" of 2026:** SQL and Python are the baseline for entry. My analysis shows that nearly **50% of all data postings** require SQL proficiency. The industry is moving toward a **"SQL + AI" workflow**, where analysts use AI for boilerplate code while focusing on complex architecture.
- **The Value of the "Full Stack" Analyst:** There is a clear salary premium (averaging **15-25%**) for analysts who can bridge the gap between technical extraction and business communication (Power BI/Tableau).
- **Specialization Pays Off:** Specializing in **Cloud environments** (Snowflake/BigQuery) or **Advanced Aggregations** (Window Functions) significantly reduces competition and increases salary offers.
- **The Remote/Hybrid Divide:** While fully remote roles are selective, **hybrid roles** remain a primary growth area for entry-level analysts.
- **Precision over Volume:** The market now rewards **precision**. Employers value analysts who can identify *why* data is missing and what that means for the bottom line.
